# 🎙️ Fluency AI — Real-Time English Speaking & AI Fluency Coach

> Elevate your spoken English fluency with instant AI roleplay conversations, real-time grammar corrections, and natural phrasing upgrades powered by Gemini & ChatGPT models.

---

## 🌟 Key Features

- **Real-Time Voice & Chat Modes**: Seamlessly switch between hands-free interactive Voice mode and text Messenger mode.
- **Instant Grammar Fix & Upgrades**: Immediate feedback on grammatical precision with highlighted corrections.
- **Native Alternatives**: Multiple alternative phrasings (Casual Native, Professional, Expressive) tailored to different scenarios.
- **Multi-Model & Multi-Persona Support**:
  - Google Gemini 4 Argon, Gemini 3.8 Flash, 3.5 Lite (Kore, Puck, Aoede personas)
  - OpenAI ChatGPT GPT-4o, GPT-4o Mini, o3-mini (Coral, Ash, Sage personas)
- **Roleplay Scenarios**: Casual Daily Talk, Job Interview, Business Meeting, Travel & Concierge, Pronunciation & Shadowing.
- **Adaptive Fluency Levels**: Basic (Lv.1), Intermediate (Lv.2), and Advanced (Lv.3).
- **Personal Review Notebook**: Automatically track speaking metrics, bookmark grammar fixes, and review practice sessions.

## 🚀 Getting Started

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/siriuspang/Fluency-AI.git
   cd Fluency-AI
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local server:**
   ```bash
   npm start
   ```
   Open `http://localhost:3000` in your web browser.

---

## ☁️ Deployment

### Cloudflare Pages
1. Push this repository to GitHub.
2. In Cloudflare Dashboard, go to **Workers & Pages** -> **Create Application** -> **Pages** -> **Connect to Git**.
3. Select `Fluency-AI` repository.
4. Set Build Settings:
   - Framework preset: `None`
   - Build output directory: `.`
5. Click **Save and Deploy**.
